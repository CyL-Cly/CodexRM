# Linux 微信机器人管理

在 Linux Agent 设置页打开「微信机器人」。新装先检查 Debian 或 Ubuntu amd64、Docker、Compose 和端口，再按发布清单拉取镜像。公共服务启动并通过管理接口认证后，向导创建第一个机器人。扫码时可以提交微信显示的六位安全验证码。登录后面板会尝试同步通讯录并配对本机 Agent。同步或配对失败时可以在「机器人账号与登录」重试。

在无桌面主机以 `--loopback-settings` 启动 Agent，可以通过 SSH 使用固定设置端口。端口及随机密码保存在 `connection.json` 相邻的 `settings-access.json`。SSH 转发两端使用同一端口，再通过浏览器打开本机地址并输入密码。

使用「接管已有安装」时，面板通过 wxbot 管理接口验证凭据，记录服务、版本及数据路径，并沿用当前配对。接管后的服务维护支持启停、重启和升级机器人客户端。客户端升级保留现有目录挂载、配置、协议容器和数据库。包含未知网络或 Docker 卷的客户端会停在检查步骤并告知原因。第三方部署的公共服务升级、备份、恢复及卸载仍由原部署工具管理。

由 CodexRM 安装的实例支持栈备份、恢复、公共服务与机器人客户端升级，以及保留数据卸载。升级后探测新的客户端能力。失败时恢复升级前的数据和客户端。现有协议容器继续使用创建时锁定的协议版本。

## 安装与镜像

运行账号需要能够访问本机 Docker。置备系统服务时，管理员可在已校验的 Linux 安装包目录执行以下命令，将 Docker 软件包安装授权限于一个固定的 systemd 服务。

```sh
sudo sh install-wxbot-bootstrap.sh ./codexrm-agent <agent-user>
```

全新安装默认跳过词云、即梦和 wxbot 自带的 MCP 服务。需要这些组件时，可在安装前展开「可选服务」勾选。重试沿用任务记录的选择，升级沿用已部署的组件。网易云音乐当前不随 CodexRM 安装。

安装 Docker 和 Compose 时，引导服务从当前主机实时获取 [CERNET Docker CE 镜像列表](https://mirrors.cernet.edu.cn/api/apt/mirrorlist/docker-ce)。APT 按返回顺序下载索引和软件包，镜像不可达时尝试下一站。列表不可用时使用清华和中山大学镜像。引导服务校验 Docker 的 APT 主密钥指纹，再由 APT 校验签名和软件包摘要。Docker 的访问权限由主机管理员管理。便携 Agent 也支持用一次性系统授权运行 `codexrm-agent -wx-install-helper`。

wxbot 镜像清单文件名为 `wx-images.json`，放在 Agent 二进制旁，也可以用 `CODEXRM_WXBOT_IMAGE_LOCK` 指定。清单所有镜像均采用带 SHA-256 摘要的完整仓库地址。Compose 公共服务、动态机器人客户端、微信协议端和备份工具使用各自的固定版本。需使用包含本次 CodexRM 接入改动的 wxbot 客户端和管理后端。配置国内仓库后，执行 `build/scripts/release-wxbot-images.sh`，从两个 wxbot 仓库的完整提交 SHA 构建并发布镜像。输入清单的公共镜像键如下。

| 镜像组 | 清单键 |
| --- | --- |
| 持久化 | `redis`、`mysql`、`qdrant` |
| 微信协议及服务 | `protocol`、`wechat-auth`、`slider`、`uuid` |
| 按需安装 | `word-cloud`、`jimeng`、`mcp` |
| 管理与运维 | `admin-web`、`nginx`、`backup` |

发布脚本补齐 `client` 和 `admin-api`，并逐项拉取校验 amd64 镜像。构建环境可用 `WX_DOCKERFILE_FRONTEND`、`WX_GO_BUILD_IMAGE` 和 `WX_ALPINE_BUILD_IMAGE` 指向可访问的构建镜像。发行时使用已校验且用户设备可访问的镜像仓库。通过 `build/scripts/release-all.ps1 -LinuxOnly -WxBotImageLock <path>` 将清单和引导服务带入 Linux 包。Agent 本机设置页和 wxbot 服务应从可信管理网络访问。新装的 wxbot 对外映射默认只绑定回环地址。

## 群聊与转发记录

每个群独立配置。启用后默认只响应 @机器人，群员共享一条会话。管理员可切换为全部消息或成员会话，并在名单中限制可使用的成员。共享会话的停止和重置权限单独分配。群内可授权 Web 查询命令，群里的工作区工具权限独立于好友的私人权限。

合并转发将有序记录写成 `transcript.md`，媒体保存在同一目录，`media.json` 标识原件、缩略图、失败和不可用条目。工具模式向 Codex 提供本机绝对路径，仅聊天模式由 Agent 将正文和一份可用的图片加入当前轮次。记录每次最多 200 条，媒体合计最多 4 MiB。图片尝试使用微信记录中的 CDN 元数据。依赖原消息的语音、视频与文件，仅在同一会话仍有匹配原消息且协议可下载时保存。缓存默认保留 7 天，可在面板调整。
